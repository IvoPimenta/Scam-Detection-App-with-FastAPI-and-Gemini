# 🛡️ Scam Detection App — Emails & Malicious URLs

A security-focused AI application to detect scam emails and suspicious URLs, built with FastAPI and enhanced with Google Gemini for contextual reasoning

🔍 Project Description
This project is designed to help protect users from digital fraud by detecting potentially dangerous content in emails and links. It combines traditional validation methods with the advanced contextual understanding of Google Gemini, offering deep analysis and readable reports about risks and threats.

🚀 Features
Automated analysis of suspicious emails and messages

Real-time URL scanning for malicious content

Explanatory reports generated via Google Gemini

Lightweight, fast, and production-ready API

Contextual understanding of threats

🛠️ Tech Stack
Python

FastAPI

Google Gemini GenAI

Regex and link validation

Pydantic (data validation)

Uvicorn (ASGI server)

🌟 Highlights
Context-aware detection powered by LLMs

Human-readable summaries explaining risks

FastAPI backend with high performance and scalability

Ideal microservice base for cybersecurity platforms
